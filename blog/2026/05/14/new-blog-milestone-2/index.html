Today, I have completed milestone 2 of my new blog!

Now, each blogpost has tags, which can be clicked to see other posts with that same tag!

The homepage of my website already had a tagging system for the projects, so I was able to take that system, make it a bit more generic, and then use it for the blog tags as well.

I'm not quite ready to publicise the blog fully, just quite yet, as I would like to get some more testing in first.

I'll ask my friends to look through (the whole blog section of) my site and provide feedback.

Hopefully, there'll be some good stuff in there, so I can make my website even better! :)

Once I've implemented all that feedback, I will continue onto milestone 3: syntax highlighting for codeblocks.
(I mentioned my plans for that in the previous post in this series)
